🧠 Leitner 五箱系统 — 如何运作

Box 1 · 每天 → Box 2 · 隔1天 → Box 3 · 隔3天 → Box 4 · 隔7天 → Box 5 · 已掌握

所有新卡片从 Box 1 开始。每次复习：答对 → 升一箱；答错 → 退回 Box 1。
箱子越高，复习间隔越长。到达 Box 5 的概念代表你已牢固掌握，每两周复习一次即可。
每日只需复习「到期」的卡片（约 5–15 张），5 分钟就够。进度自动保存到浏览器。
